# ✅ Чек-лист перед сменой лагеря

Пройдите этот список **до заезда детей**. Отметьте каждый пункт.

## Оборудование

- [ ] Ноутбук / мини-ПК подключён к питанию (не от батареи).
- [ ] Отключён режим сна Windows: `powercfg /change standby-timeout-ac 0`
      и «Никогда» для отключения дисплея/сна в параметрах питания.
- [ ] Интернет работает (Wi-Fi/кабель). Проверьте, что соединение стабильно.
- [ ] USB-аудиоинтерфейс / звуковая карта подключены к микшеру/усилителю.
- [ ] Кабели до рупоров целы, усилитель включён.

## Программное обеспечение

- [ ] Установлен mpv: `mpv --version` выводит версию.
- [ ] Выбран правильный аудиовыход: `python -m agent.cli list-audio-devices`,
      значение вписано в `.env` → `MPV_AUDIO_DEVICE`.
- [ ] Тестовый звук слышен в рупорах: `python -m agent.cli test-audio`.
- [ ] Player Agent запущен и показывает `READY` (или задача автозапуска активна).
- [ ] В боте `/devices` показывает 🟢 **онлайн**.

## Контент

- [ ] Все нужные песни синхронизированы на устройство
      (в Mini App/боте статус ✅ «Загружен на устройство»).
- [ ] Сценарии настроены и привязаны к трекам: Сбор, Подъём, Завтрак, Обед,
      Ужин, Игры, Служение, Отбой, Срочное объявление.
- [ ] Библиотека объявлений записана и загружена.

## Громкость и безопасность

- [ ] Громкость проверена на комфортном уровне (не превышает безопасный порог
      без необходимости).
- [ ] `MAX_SAFE_VOLUME` и `ABSOLUTE_MAX_VOLUME` заданы разумно.
- [ ] **Аварийный стоп проверен**: кнопка «🛑» в боте/Mini App и локально
      `python -m agent.cli stop` — звук прекращается.
- [ ] Горячая клавиша аварийной остановки настроена (если используется).

## Доступ и роли

- [ ] OWNER (владелец) имеет доступ и может всё.
- [ ] ADMIN(ы) добавлены и могут управлять музыкой/расписанием.
- [ ] OPERATOR(ы) добавлены и могут запускать разрешённые сценарии.
- [ ] Неизвестные / посторонние пользователи **НЕ** имеют доступа
      (проверьте: посторонний Telegram-аккаунт получает «Доступ запрещён»).

## Расписание и время

- [ ] Расписание соответствует распорядку текущего дня смены.
- [ ] Системное время ноутбука верное.
- [ ] Часовой пояс `Europe/Chisinau` задан (`APP_TIMEZONE`), время событий
      отображается корректно.
- [ ] Нет конфликтующих событий в один момент (бот/Mini App предупреждает).

## Финальная проверка (боевой прогон)

- [ ] Оператор открывает бота → «🏕 Сбор» → подтверждает → музыка идёт в рупоры.
- [ ] `/now` показывает трек, громкость, кто запустил.
- [ ] Пауза / продолжение / стоп работают.
- [ ] При выключенном Player Agent бот показывает «🔴 Рупор недоступен».

> Держите этот чек-лист распечатанным рядом с ноутбуком звуковой системы.
